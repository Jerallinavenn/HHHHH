# Fnaf_Patody 🎃

Пародия на FNAF 1, сделана на **Godot 4.4.1**.

## О проекте
Игрок сидит в офисе охранника с 12 до 6 утра: следит за энергией, закрывает двери, включает свет и пытается пережить ночь. Пока в разработке: камеры и аниматроники ещё не реализованы.

## Как запустить
1. Установите [Godot 4.4.1](https://godotengine.org/download/archive/4.4.1-stable/)
2. Откройте Godot → Import → выберите `fnaf_patody/project.godot`
3. Нажмите F5 (Run Project)

## Структура
- `fnaf_patody/maingame.tscn` — главная сцена (офис + UI)
- `fnaf_patody/maingame.gd` — вся игровая логика
- `fnaf_patody/button.gd` — логика кнопок дверей/света
- `fnaf_patody/*.gdshader` — шейдеры (фишай, маска света)
